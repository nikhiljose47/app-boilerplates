Add open graph & twitter meta tags
Helps with link previews on social media:

this.meta.addTags([
  { property: 'og:title', content: 'Handmade Soaps' },
  { property: 'og:description', content: 'Natural soaps with essential oils.' },
  { property: 'og:image', content: 'https://yourdomain.com/assets/soap.webp' },
  { name: 'twitter:card', content: 'summary_large_image' }
]);
